# Каталог приложений для перекрёстного продвижения

Две самостоятельные страницы для кнопки `More Games` / `More Apps` в приложениях:

- iOS: `https://nadkyxa.github.io/more-apps/ios.html`
- Android: `https://nadkyxa.github.io/more-apps/android.html`

Адреса станут доступны после публикации репозитория через GitHub Pages.

Страницы не используют стили, навигацию и скрипты основного маркетингового сайта. Общий файл оформления — `styles.css`. Из существующей папки `../assets/` используются иконки и скриншоты; её нужно сохранить при публикации.

Контент и ссылки взяты из существующих страниц приложений. iOS содержит три игры, Android — четыре игры и два приложения. Ссылки ведут прямо в соответствующий магазин и работают без JavaScript. Новые приложения добавляются вручную в HTML соответствующей платформы.

При последующем подключении WebView приложение должно перехватывать ссылки `apps.apple.com` и `play.google.com` и открывать их системным обработчиком магазина. Обработка ссылок на почту также остаётся на стороне приложения. Эта интеграция в текущую задачу не входит.
